# Sources and redistribution boundaries

This collection contains agent instructions, factual reference notes, illustrative
assembly routines, and Python helpers. Source citations within the specialist
references remain attached to their technical claims.

The MIT license applies to the collection's original material. It does not
grant rights to third-party publications or software linked from these files.
The following research materials are external sources, not bundled assets:

- Bob Sander-Cederlof's *Apple Assembly Line*, available through the
  [Scott Alfter archive](https://alfter.us/computers/apple-ii/publications/apple-assembly-line/).
- The [6502.org Source Code Library](https://6502.org/source/) and tutorials.
- Apple reference manuals, technical notes, ROM listings, and ProDOS manuals.
- Merlin manuals and the [Brutal Deluxe Merlin32 documentation](https://brutaldeluxe.fr/products/crossdevtools/merlin/).
- The additional books, articles, charts, and sites cited within the references.

Do not infer redistribution permission from a source being available online.
The public distribution excludes mirrored publications, third-party source
archives, ROMs, disk images, and binary downloads. It links to sources instead.

Runtime dependencies are installed separately and retain their own licenses:
[py65](https://github.com/mnaberez/py65) and the optional
[MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk).
Merlin32, CiderPress2, and any emulator are separate tools, not included code.
